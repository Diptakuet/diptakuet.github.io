uGen is a multi-agent, retrieval-augmented generation (RAG) system designed to automate the end-to-end lifecycle of microarchitectural attack research. Given a high-level security objective, uGen autonomously identifies unexplored attack surfaces, retrieves relevant academic and technical knowledge, generates functional attack code, validates it against real hardware, and iteratively improves both the attack and potential defenses. This work advances automated security evaluation and lowers the barrier for systematic vulnerability discovery across diverse processor architectures.
